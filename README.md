# Stream-Registration-Form
A responsive higher secondary stream registration form built using HTML and CSS.

## Features

- Student information form
- Guardian details
- Contact information
- Stream selection
- Optional subject selection
- Document upload fields
- Responsive design
- Clean and simple user interface

## Technologies Used

- HTML5
- CSS3
